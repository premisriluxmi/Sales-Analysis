# Sales Analysis

A beginner-level Python project that analyzes sales values and calculates basic sales statistics.

## Objective

To analyze a collection of sales values and calculate:

- Total sales
- Average sales
- Highest sale
- Lowest sale

## Technologies Used

- Python 3
- Jupyter Notebook

## Python Functions Used

- `sum()` – to calculate the total sales
- `len()` – to find the number of sales values
- `max()` – to find the highest sale
- `min()` – to find the lowest sale

## Results

| Analysis | Result |
|---|---:|
| Number of Sales | 20 |
| Total Sales | 395550 |
| Average Sales | 19777.5 |
| Highest Sale | 32000 |
| Lowest Sale | 9500 |

## Explanation

The total sales amount is ₹3,95,550 for 20 sales values.

The average sale is ₹19,777.5, which represents the average value of the sales.

The highest sale is ₹32,000, while the lowest sale is ₹9,500.

These results provide a basic overview of the sales data and help understand the overall sales performance.

## How to Run

1. Open the `Sales_Analysis.ipynb` file in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. View the calculated sales results.
